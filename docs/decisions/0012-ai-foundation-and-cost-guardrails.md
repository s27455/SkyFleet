# 0012 — AI foundation and cost guardrails (Feature 024)

**Status:** Accepted for the MVP and implemented. The foundation is tested offline and on PostgreSQL; AI is **disabled by default** and nothing calls it. One real smoke request was made on 2026-11-15 (see Consequences); no other real request has been made.

## Decisions

- **One gateway, nothing else talks to the provider.** `app/ai/gateway.py` (`AiGateway.ask`) is the single entry point. `app/ai/anthropic_transport.py` is the only module that imports the Anthropic SDK, behind a small `AiTransport` protocol, so every test uses a fake transport. `app/ai` imports no domain module (drones, orders, missions, simulation) and nothing outside it imports `app/ai` yet; an architecture test enforces both. The model receives text only: no tools, no database access, no write actions. There is no public AI endpoint (the API has no authentication yet).
- **Fail closed, off by default.** `SKYFLEET_AI_ENABLED` defaults to false; while it is false nothing is validated, so a missing key never stops the API or the worker. When enabled, every request first passes `readiness.config_problems` (key present, model on the allowlist, price entry not older than 90 days, every limit at or below the MVP maximum). The limits can be tightened by settings but never raised without a code change.
- **Model and prices together.** `pricing.py` holds an explicit allowlist: the model id (`claude-haiku-5-5`), its price tiers in integer nano-USD per token and the date they were verified against the official documentation. An unlisted model is refused.
- **MVP limits.** 16 KiB total input (UTF-8 bytes of system instructions, context and question), 500 question characters, 400 output tokens, 10 requests per hour, 30 s between requests, one provider request in flight, USD 4.00 lifetime ceiling, SDK retries disabled (`max_retries=0`), 30 s request timeout, 15 min back-off after a key, balance, spend-limit or invalid-request failure. Provider-side caps (Console spend limit, auto-reload off) are operator steps and are not a substitute.
- **Durable reservation before every call.** `SqlBudgetStore.reserve` runs in one transaction that locks the single `ai_budget_state` row (`SELECT ... FOR UPDATE`), sweeps abandoned reservations, verifies that the budget row and the log agree, checks every limit and the ceiling, adds the request's worst-case cost to `reserved` and writes a `RESERVED` row. Concurrent requests (API and worker are separate processes) are serialised by that lock. Nothing is sent unless the reservation committed; any database error means no request.
- **The token bound is an assumption, so it is checked.** Reserved input tokens = UTF-8 bytes of everything sent + 1,024; output = the full cap; the base price tier is assumed. The provider's own token counts are compared with the reservation after every call; if either is exceeded the real cost is charged and the gateway halts itself (`ESTIMATE_EXCEEDED`) until a person clears it.
- **Conservative settlement.** Success charges the real cost. A provider rejection (401, 402, 403, other 4xx, any 429) is refunded. An unclear outcome (timeout, connection error, 5xx, 529, unclassified) keeps the whole reservation as spent. An unsettled reservation older than its lease (10 minutes: the SDK caps a non-streaming request at 10 minutes, and four times the per-phase timeout plus a margin is the other bound; the larger wins) is charged in full as `UNKNOWN`; a late report can only add cost. The sweep does not free the slot: for one more lease no new request may start, because a swept request might still be running, so a second provider request begins at least two leases (20 minutes) after an unsettled first one. If the books disagree the store halts itself (`ACCOUNTING_INCONSISTENT`).
- **Nothing sensitive is stored or logged.** `ai_request_log` has numeric and code columns only (no prompt, context, answer, key or provider message), and the logger writes ids, codes, token counts and costs. The key is a `SecretStr` (never in `repr` or a dump) read from `ANTHROPIC_API_KEY` in the Git-ignored `backend/.env` only; the client is built with a fixed base URL so `ANTHROPIC_BASE_URL` cannot redirect it.
- **Tests cannot reach the provider.** A suite-wide autouse fixture removes the Anthropic environment variables, makes constructing a real SDK client fail and rejects any non-loopback connection; AI tests build `Settings(_env_file=None)` with a fake key.
- **Schema.** Migration `0019` adds `ai_budget_state` (one row, `name = 'anthropic'`, created by the gateway on first use) and `ai_request_log` (one row per attempt, never deleted). The tables have no foreign keys to simulation data and nothing in the application truncates them.

## Consequences

- Wiring the gateway into an endpoint, the Fleet Operations Agent or any tool use is a later, separately approved feature; it must keep the limits, the allowlist and the no-secrets rule, and needs authentication first.
- Price and model data must be re-verified against the official documentation before AI is ever enabled and at least every 90 days (the gateway refuses stale prices).
- A halted gateway stays closed until a person clears `ai_budget_state.halted` after investigating; there is no automatic reset.
- The migration downgrade drops both tables and with them the spend history; do not downgrade after real requests exist unless that is intended. Older migration round-trip tests exclude these two tables because `0019` sits above the revisions they downgrade to.
- `ai_request_log` grows by at most 10 rows per hour at the limits above; no pruning is needed for the MVP.

## Smoke test (2026-11-15)

One paid request through the real gateway (model `claude-haiku-5-5`, fixed one-word prompt, 32 output tokens, AI enabled for that single process only): 109 input and 4 output tokens, charged USD 0.0000129 against a reservation of USD 0.0001499. The ledger and the budget row agreed afterwards (one `SUCCEEDED` row, spent equal to charged, nothing reserved, not halted). The temporary script and its tests were deleted; nothing in the repository can send a request except through `AiGateway`, which no code calls yet.
